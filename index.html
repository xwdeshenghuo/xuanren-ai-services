常见问题

账号和数据归谁？会不会被绑定？

全部归你。平台账号、服务器、数据、配置都开在你自己名下，交付时有完整的账号与配置交接清单。停掉维护，你拿着文档和配置也能自己继续用，不存在“赎金”一说。

我完全不懂技术，能用吗？

可以。交付包含使用说明，C 档还含一次线上培训。日常操作就是改改答案、看看报表这类动作，不需要你碰代码；复杂调整走维护服务即可。

机器人答错了怎么办？

问答只基于你提供的知识库回答，答不上来会自动转人工并记录问题，每周给你一份“未命中问题清单”，补上答案后命中率会逐步变好。它替代的是重复问答，不替代你的人工客服把关。

除了套餐价，还有哪些费用？

平台订阅费、大模型 API 调用费、服务器/域名等第三方费用由你自付（用你自己的账号开通，金额取决于你选的平台和用量，诊断时会先帮你估算）。我这边只收套餐费和你自愿订的维护费，没有其他名目。
